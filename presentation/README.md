# Pitch deck

A 21-slide deck that explains the whole project to any audience: a faculty member or guide, a student, a recruiter
or someone new to ML. It runs 17 main slides plus 3 appendix slides and a closing slide. Every slide has speaker notes.

| File | Use it for |
|---|---|
| [Entity-Resolution-Amazon-ML-Challenge-2026.pdf](Entity-Resolution-Amazon-ML-Challenge-2026.pdf) | reading, printing, sharing |
| [Entity-Resolution-Amazon-ML-Challenge-2026.pptx](Entity-Resolution-Amazon-ML-Challenge-2026.pptx) | presenting: open in PowerPoint and use Presenter View to see the notes |

Each PowerPoint slide is a full-slide image, so the text can't be edited in PowerPoint. The notes can.

**Storyline:** the problem in one example → why it matters → why it is hard → shortlist, judge, decide → data and
metric → architecture → candidates and the recall ceiling → features and LightGBM → cross-encoders and stacking → France →
the journey → what went wrong → results → how it applies to a real business → what's next → start learning.
**Appendix:** models, validation and leakage, glossary.

Every number on the slides comes from this repository's documentation and the team's logs.
